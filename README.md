# Icepool

Hello friends and welcome to “Icepool”. “Icepool” is a collection of recovered and recreated Spineworld assets and artwork.

Spineworld was an MMO game aimed at older teens created by Swedish company Playdo. That's Playdo not Play-doh, by the way.
